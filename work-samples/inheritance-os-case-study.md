# Inheritance OS - AI-Powered Financial Afterlife Planner

## Snapshot

- Role: Lead AI / Full-Stack Developer
- Context: Fidelity Hackathon 2025
- Stack: React.js, Node.js, MongoDB, Python, Gemini API, Docker, GCP, GitHub Actions CI/CD
- Delivery: Working MVP shipped in 48 hours

## Problem

Estate planning is slow, paperwork-heavy, and difficult for families to understand. The project targeted
unclaimed inheritance workflows and cross-generational financial planning, with a product concept aligned to
Fidelity's wealth-management ecosystem.

## What I built

- React-based asset dashboard for beneficiaries, assets, document status, and planning progress.
- Node and MongoDB backend structure for user, asset, and document records.
- Gemini-powered Wealth Intelligence Engine for document parsing and tax-minimization strategy generation.
- Dockerized services deployed through GitHub Actions to GCP Cloud Run.
- SOC 2-aligned role-based access concept for secure family, advisor, and admin views.

## Results

- Shipped a working MVP within a 48-hour hackathon sprint.
- Reduced estate-planning workflow time by an estimated 60% through AI-assisted document parsing.
- Presented a scalable product story connected to the Great Wealth Transfer and high-value asset planning.

## Full-stack relevance

This project is a strong internship sample because it shows practical product thinking: a React frontend,
API-backed data model, AI integration, deployment flow, and security-aware access control.

## What I would improve next

- Add automated API tests around document upload, parsing, and recommendation flows.
- Add audit logs for sensitive document and role changes.
- Add a cleaner dashboard for advisors to compare tax strategies.
- Split the AI parsing worker from the main API service for safer scaling.
